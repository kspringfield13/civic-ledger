# civic-ledger system blueprint

Deliverables from the multi-agent design initiative (2026-07-03). Each doc was
drafted by a specialist agent, red-teamed, and synthesized by the command
model. Everything here is subordinate to the repo's governance docs
(`LEGAL_AND_ETHICAL_BOUNDARIES.md`, `DATA_SOURCE_POLICY.md`,
`EVIDENCE_STANDARD.md`, `DETECTION_PRINCIPLES.md`, `GOVERNANCE.md`) — if a
blueprint doc conflicts with those, the governance docs win.

All outputs of the system this blueprint describes are **risk signals and
case leads for human review — never findings or accusations of fraud.**
